# 《朋友收集》色盤對照工具

這是一個可直接在瀏覽器開啟的單頁靜態工具，適合拿來分析圖片用色，並對照《朋友收集》風格的色盤定位。

## 功能

- 上傳圖片並分析主要顏色
- 內建 221 色色卡
- 自動比對最接近的拼豆 / 色卡候選色
- 顯示 HEX、RGB、色差與前 3 名候選色
- 模擬《朋友收集》色盤位置
- 支援桌機與手機瀏覽

## GitHub Pages

這個專案是純前端靜態頁面，根目錄的 [index.html](./index.html) 可直接作為 GitHub Pages 入口頁。

建議設定：

1. Repository visibility：`Public`
2. GitHub Pages source：`Deploy from a branch`
3. Branch：`main`
4. Folder：`/ (root)`

啟用後，GitHub Pages 會直接發布這個單檔工具。

## 本機使用

直接以瀏覽器開啟 `index.html` 即可使用。
